# Module 01 — Introduction to SQL and Databases

## Module Goal

By the end of this module, you will understand **what a database is, what SQL is, how SQL commands are categorized, and how to actually run a query against a real database** — before you write any complex logic. Every later module builds on this mental model. Skipping it is the #1 reason people memorize query syntax without ever understanding *why* SQL is shaped the way it is.

## Topics Covered in This Module

1. **[What Is a Database and a DBMS?](01-what-is-a-database-and-a-dbms.md)** — What a database actually is, what a DBMS does, and what makes a database *relational*.
2. **[What Is SQL?](02-what-is-sql.md)** — Definition, why SQL is a *declarative* language, and the SQL standard (ANSI/ISO) vs. real-world implementations.
3. **[Categories of SQL Commands](03-categories-of-sql-commands.md)** — DDL, DML, DQL, DCL, and TCL: the five buckets every SQL statement falls into, and why that grouping matters.
4. **[Setting Up PostgreSQL](04-setting-up-postgresql.md)** — Installing PostgreSQL, connecting with `psql`, and an optional GUI client, so you have a real database to practice against.
5. **[Your First Query](05-your-first-query.md)** — Creating a table, inserting rows, and querying them — dissected statement-by-statement, plus common beginner mistakes.
6. **[Module Summary](06-module-summary.md)** — Consolidated recap.

## Prerequisites

- General computer literacy: comfort with a command line / terminal is helpful but not required — every command is explained.
- No prior database or SQL experience required.
- No specific software required yet — installation is covered in this module (Topic 4).

## How to Study This Module

Read in order. Topics 1–3 build your conceptual model (what a database *is*, what SQL *is*, how its commands are organized) — read these even if you're impatient to start typing queries, because Topics 7 onward assume this vocabulary. Topic 4 gets your environment ready. Topic 5 is your first hands-on win: you'll create a table and query it, and understand exactly what each keyword did.
